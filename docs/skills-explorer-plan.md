## Anatomi halaman skill (`/skills/[skill]`)

1. **Header**: nama skill, satu kalimat, jumlah project, tools utama.
2. **How I do it (metode)**: 5–6 langkah khusus skill itu. Contoh untuk Machine Learning:
   Frame the problem → Explore the data (EDA) → Engineer features → Train & validate → Explain the model → Deploy as an app.
   Tiap langkah: satu kalimat + tools yang dipakai + contoh dari project nyata.
3. **Lab**: grid semua project skill itu, dengan filter jenis (untuk ML: Classification · Regression · Clustering · Time series · Anomaly detection · Recommendation) dan pencarian (Fuse.js).
   Kartu project: judul, masalah 1 kalimat, metode, metrik utama, label "Live demo" kalau ada.
4. **Next skill**: tombol ke skill berikutnya.

## Anatomi halaman project (`/skills/[skill]/[project]`)

1. Masalah (kenapa project ini ada)
2. Data (sumber, ukuran, fitur penting)
3. Pendekatan (model yang dicoba, kenapa yang terpilih menang)
4. Hasil (metrik asli dari notebook, grafik)
5. **Demo**: Streamlit di-embed (iframe) atau tombol "Open live demo"; untuk beberapa project bisa dibuat demo kecil langsung di browser (slider input → prediksi).
6. Link kode (GitHub / notebook)

## Build notes (kode step by step) di setiap halaman project (11 Nov 2026)

- Bagian **Code** di tiap halaman project diambil otomatis saat build dari kode asli: `src/lib/code-docs.ts` membaca `ml/train.py` dan memecah tiap fungsi training di komentar `# STEP: Judul | penjelasan`; fungsi browser (TypeScript) dipilih per project di `src/data/code-docs.ts`.
- Tombol: salin per langkah, salin/unduh script lengkap (import + helper yang dipakai + fungsi), jadi pengunjung bisa menjalankannya sendiri setelah mengunduh dataset. Diuji: script salinan telco, heart, mall dan bank menghasilkan JSON yang identik dengan situs.
- **Project baru wajib:** beri penanda `# STEP:` di fungsi training-nya (penanda pertama tepat di bawah baris `def`), tambahkan nama fungsinya ke `codeDocConfig.projectFunctions`, dan daftarkan fungsi browser-nya di `codeDocConfig.projects`.

Project DL ke-11: **Traffic Counter** (11 Nov 2026): kamera lalu lintas live London (TfL JamCam, ~900 kamera, data terbuka) lewat dua route Next.js, EfficientDet-Lite0 + tracker buatan sendiri (IoU + prediksi gerak) + hitungan lintas garis dengan arah; klip dianalisis frame demi frame lewat seek (12 fps) supaya hitungan sama di semua perangkat; mode kamera sendiri.
Project DL ke-12: **Head & Blink Keyboard** (11 Nov 2026, aksesibilitas/AAC): pose kepala → penunjuk (kalibrasi netral + One Euro), kedip sengaja 0,45–2,5 detik (kedip alami diabaikan), dwell, scanning baris/kolom dengan kedip saja, prediksi kata EN/ID, text-to-speech, panah + Spasi sebagai fallback/switch input. Update (11 Nov 2026, permintaan user): penunjuk bisa memakai **mata** (titik iris 468/473 relatif sudut & kelopak mata, kalibrasi 5 titik, dibekukan saat kedip, klik memakai posisi ~120 ms sebelum kelopak bergerak) dan **klik kedip instan** (tepi buka→tutup, refraktori 0,35 detik) jadi bawaan; mode tahan 0,45 detik tetap ada.

Project DL ke-13: **Air Synth** (11 Nov 2026, permintaan user: main musik dengan jari, satu tangan ubah nada, tangan lain ubah yang lain): dua tangan dari model tangan MediaPipe yang sama (tanpa unduhan baru). Mode **Theremin**: tinggi tangan kanan → nada pada skala (pentatonik/mayor/minor/blues, snap dengan margin atau glide), tangan kiri → volume, kepalan = mute, jempol-telunjuk = vibrato. Mode **Finger chords**: jumlah jari kiri 1–5 → C/F/G/Am/Dm (tahan 4 frame), jempol kanan menyentuh telunjuk/tengah/manis/kelingking → 4 nada akor, plus bass. Synth Web Audio (lead + vibrato, 4 voice pluck, bass, filter Tone, reverb buatan, limiter), jejak nada + osiloskop, fallback mouse/keyboard (1–5, A S D F). Aturan hitung jari dicek di 905 tangan nyata ASLNow! lewat `scripts/check-air-synth.mjs` → `src/data/models/air-synth.json` (97,1% benar; ambang jempol 0,55 dipilih dari data yang sama).
